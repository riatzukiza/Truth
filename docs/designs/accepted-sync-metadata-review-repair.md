## Negative controls and error surface

Index tests must separate staging from restoration in the working tree. Include allowed metadata, forbidden product path, misleading prefix, missing inherited path, unmerged stage and mode mismatch. Prefix tests include actual indexed invalidity with valid working-tree bytes, legitimate append, and wrong base identity. Receipt tests bind a stable original envelope/time, exact replay, conflicting content, malformed legacy input and either a supported simultaneous retry or an enforced refusal under documented single-writer admission. Capture tests use finite cheap fixture commands, timeout with flushed stdout/stderr, nonzero exit and the declared owned-child lifecycle; never launch a shared service or intentionally leave a background process.

A failing negative fixture is RED evidence until the successor refuses it. Do not relabel the old helper's exit 0 as correct simply because the final historical b239 tree is independently preserved. Conversely, a buggy helper is not proof that the actual b239 tree lost source bytes. Evidence and product correctness are distinct conclusions.
